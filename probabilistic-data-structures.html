Taxonomy of Probabilistic Data Structures (AI-generated)

Structures providing space-efficient approximate answers with well-characterised probabilistic guarantees over collections.

Scope. This document covers data structures that sacrifice exactness for sub-linear space (or time) while providing bounded, analysable error. The term "asymmetric guarantee" is used broadly: some structures have strictly one-sided error (e.g., Bloom filters can only produce false positives, never false negatives), while others have symmetric but tightly bounded error (e.g., HyperLogLog). Both classes are included, with the error direction explicitly noted.

1. Approximate Membership Query (AMQ) Structures One-Sided

Query: "Is x ∈ S?" → { Definitely No | Probably Yes }

All AMQ structures share the core guarantee: no false negatives. If the structure reports an element is absent, it is certainly absent. False positives occur at a tuneable rate ε. The key differentiators are support for deletion, dynamism, cache behaviour, and space efficiency relative to the information-theoretic lower bound of n · log₂(1/ε) bits.

Bloom Filter 1.44 log₂(1/ε) at optimal k ≈ (1 − e−kn/m)k O(k) O(k) No Yes (OR) Yes The canonical AMQ. ~44% overhead vs information-theoretic lower bound. k independent hash functions probe k bit positions.
Counting Bloom Filter ~3–4× Bloom (typically 4 bits/counter) Same as Bloom O(k) O(k) Yes Yes Yes Replaces bits with counters. Counter overflow is possible (typically mitigated at 4-bit width). Deletion can cause false negatives if element was never inserted.
Blocked Bloom Filter Slightly worse than Bloom for same m Higher than standard Bloom at same space O(k), 1 cache line O(k), 1 cache line No Yes Yes Each element maps to one cache-line-sized block. Dramatically better cache performance at modest FPR increase. Used in databases (e.g., Apache Impala).
Cuckoo Filter (2 + 3/f) / α bits/element (f = fingerprint bits, α = load factor) ε ≈ 2b/2f (b = bucket size) O(1) amortised, 2 lookups O(1) amortised Limited No Yes Better than Bloom when ε < 3%. Deletion is supported but can introduce false negatives if deleting items not present. Not easily mergeable. Based on cuckoo hashing of fingerprints.
Quotient Filter ~10–25% overhead vs Bloom Controlled by quotient/remainder split O(1) amortised O(1) amortised Yes Yes Yes (resizable) Supports deletion, merge, and resize. Excellent cache locality (linear probing). Requires contiguous memory. Counting variant exists.
Xor Filter ~1.23 log₂(1/ε) ε = 1/2r (r = fingerprint bits) O(1), 3 lookups N/A (static) No No No (static) Built from 3-partite random hypergraph peeling. Must be constructed from the full set; no incremental insertion. Excellent space efficiency and query speed for immutable sets.

Ribbon Filter Approaches log₂(1/ε) (near optimal) ε = 1/2r O(1) N/A (static) No No No (static) Based on solving a banded linear system over GF(2). Closest to the information-theoretic lower bound of any practical filter. Slower construction than Xor/Fuse. Used in RocksDB.
Vacuum Filter Better than Cuckoo at high load Similar to Cuckoo O(1) O(1) amortised Limited No Yes Improves on Cuckoo by using variable-length fingerprints and alternate bucket selection. Achieves higher load factors.
Morton Filter Competitive with Cuckoo Configurable O(1), cache-optimised O(1) amortised Yes No Yes Uses compressed block metadata and underflowed fingerprint storage. Designed for SIMD-friendly cache-line access patterns. Supports deletion.
Stable Bloom Filter Similar to Counting Bloom Converges to steady-state FPR O(k) O(k + p) (p random decrements) Implicit (decay) No Yes (streaming) Designed for infinite streams. Scalable Bloom Filter Grows dynamically Geometric series ensures overall ε O(k · s) worst case (s = number of sub-filters) O(k) No No Yes (unbounded n) Chain of Bloom filters with tightening FPR. No need to know n in advance. Lookup cost grows logarithmically with number of sub-filters.
Bloomier Filter O(n · (r + log(1/ε))) Configurable O(k) N/A (static) No No No (static) Generalises Bloom to an approximate dictionary: maps keys to values with possible false positives on non-member queries. Returns correct values for members with certainty.
Key trade-off axes within AMQ structures: Static vs. dynamic — Xor/Fuse/Ribbon achieve the best space but require the full set at construction time. Bloom/Cuckoo/Quotient support incremental insertion. Deletion — Counting Bloom, Quotient, and (with caveats) Cuckoo support it. Standard Bloom and all static filters do not. Mergeability — Bloom and Quotient filters merge via bitwise OR. Cuckoo and fingerprint-based filters generally cannot.

2. Cardinality / Distinct-Count Estimation Symmetric

Query: "|S| = ?" → n̂ where P(|n̂ − |S|| > ε|S|) < δ

These structures estimate the number of distinct elements in a stream or multiset. The error is generally symmetric — the estimate can be above or below the true cardinality — with a relative error bound that decreases as space increases. The core insight exploits the distribution of hash-derived observables (leading zeros, minimum values) over the input.

Structure Space Relative Error (std. dev.) Error Direction Insert Query Merge Notes
Linear Counting O(n) bitmap in worst case; useful when n ≪ m High variance for n near m Symmetric O(1) O(m) Yes (OR) Simple bitmap. Estimate: −m · ln(V/m) where V = zero-count. Accurate when cardinality is well below bitmap size. Breaks down as bitmap fills.
PCSA (FM Sketch) O(m · log log U) bits (m = number of bitmaps) ~0.78 / √m Symmetric (biased high before correction) O(1) O(m) Yes Flajolet–Martin (1985). Stochastic averaging of bitmaps tracking max leading zeros. Foundational algorithm; superseded by LogLog/HLL.
LogLog m · ⌈log₂ log₂ U⌉ bits (typically m × 5 bits) ~1.30 / √m Symmetric (raw estimator biased high) O(1) O(m) Yes Stores max(ρ(h(x))) per register, where ρ counts leading zeros. Geometric mean estimator.
SuperLogLog Same as LogLog (with truncation) ~1.05 / √m Symmetric O(1) O(m log m) (due to sorting) Yes Truncated LogLog: discards highest registers (outlier suppression). Improved error constant over LogLog.
HyperLogLog m registers × ~5–6 bits ≈ O(ε⁻² log log U) ~1.04 / √m Symmetric (after bias correction) O(1) O(m) Yes (max) Harmonic mean estimator. The standard practical cardinality estimator. 1.5 KB for ~2% error on billions of elements. Small/large range corrections needed.
HyperLogLog++ Variable: sparse for small n, dense at m registers ~1.04 / √m (same as HLL) Symmetric (improved bias correction) O(1) amortised O(m) Yes Google's improvement. Sparse representation for small cardinalities (saves space when n ≪ m). Empirical bias correction table for medium range. 64-bit hashing eliminates large-range correction.
CPC Sketch ~20–40% less than HLL for same accuracy ~1 / √K Symmetric O(1) O(K) Yes Compressed Probability Counting (Kevin Lang, 2017). Compresses the "surprising" values. Best-in-class space efficiency for cardinality estimation. Implemented in Apache DataSketches.
KMV (K Minimum Values) O(k · log U) bits ~1 / √k Symmetric (unbiased) O(log k) (heap maintenance) O(1) Yes Maintains the k smallest hash values. Estimate: (k−1)/U_k where U_k is the k-th smallest value. Supports full set operations (union via merge, intersection via inclusion-exclusion). Basis for Theta Sketch.
No cardinality estimator in this list provides a one-sided guarantee. All can over- or underestimate. The guarantee is probabilistic: with high probability, the estimate is within (1 ± ε) of the true value. HyperLogLog's raw harmonic-mean estimator has a slight positive bias for small cardinalities, but this is corrected in practice (and in HLL++).

3. Frequency Estimation & Heavy Hitters Varies

Query: "f(x) = ?" → f̂(x) with bounded error

These structures estimate item frequencies in a data stream. The error direction differs by structure — this is the most important differentiator in this category. Count-Min Sketch guarantees it never underestimates (one-sided overestimate), while Count Sketch provides an unbiased estimator (symmetric error).

Structure Space Error Bound Error Direction Insert Query Merge Delete Notes
Count-Min Sketch O((1/ε) · ln(1/δ)) counters f̂(x) ∈ [f(x), f(x) + εN] w.p. ≥ 1−δ One-sided: overestimates only O(d) (d = depth) O(d) Yes Via negative counts d × w array of counters. Query returns min over d rows. The fundamental property: f̂(x) ≥ f(x) always. Overestimates caused by hash collisions with other elements.
Conservative Update CMS Same as CMS Same worst-case; better in practice One-sided: overestimates only O(d) O(d) No No On insert, only increments counters that are currently minimal. Reduces overestimation in practice but sacrifices mergeability and deletion. Same worst-case bounds.
Count Sketch O((1/ε²) · ln(1/δ)) counters |f̂(x) − f(x)| ≤ ε · ‖ftail‖₂ w.p. ≥ 1−δ Symmetric (unbiased) O(d) O(d) Yes Yes Uses ±1 sign hashes. Median-of-means estimator. The ℓ₂ tail guarantee makes it better for finding heavy hitters in heavy-tailed distributions. Can both overestimate and underestimate.
Space-Saving O(k) counters (k monitored items) Overestimates ≤ N/k for tracked items; guaranteed to find items with f > N/k One-sided: overestimates tracked items O(1) amortised O(1) Possible but complex No Deterministic streaming algorithm. Maintains exactly k (item, count) pairs. On new item, evicts minimum-count item and inherits its count + 1. Excellent for top-k / heavy hitter queries.
Misra-Gries (Frequent) O(k) counters Underestimates ≤ N/(k+1); finds all items with f > N/(k+1) One-sided: underestimates only O(1) amortised O(1) Yes No Deterministic. Decrements all counters when table is full. The opposite direction from CMS: f̂(x) ≤ f(x) always. Dual of Space-Saving in guarantee direction.
Lossy Counting O((1/ε) · log(εN)) Underestimates ≤ εN; finds all items with f ≥ (s−ε)N One-sided: underestimates only O(1) amortised O(1) No No Deterministic, epoch-based. Divides stream into windows of ⌈1/ε⌉. Prunes items with count ≤ epoch number. Reports items meeting threshold. Practical for frequent itemset mining.
Spectral Bloom Filter Variable (counter array) Overestimates (like CMS but via Bloom structure) One-sided: overestimates only O(k) O(k) Yes Yes Extends Bloom to frequency estimation by using counters instead of bits and querying the minimum. Conceptually similar to CMS but uses Bloom hashing.
Error direction matters for applications. Count-Min Sketch's one-sided overestimate is ideal when false positives are tolerable but false negatives are not (e.g., cache admission, anomaly detection thresholds). Misra-Gries' one-sided underestimate is preferred when you need a conservative lower bound on frequency.

4. Quantile & Rank Estimation Symmetric

Query: "What value has rank φ·N?" → v̂ where |rank(v̂) − φN| ≤ εN

Quantile sketches approximate the empirical distribution of a data stream. The guarantee is typically on the rank error: the returned value has a rank within ±εN of the target rank. Some newer structures provide relative rank error, which is more useful at extreme quantiles (p99, p99.9).

Structure Space Guarantee Error Type Insert Query Merge Notes
Greenwald-Khanna (GK) O((1/ε) · log(εN)) |rank(v̂) − rank(v)| ≤ εN (deterministic) Symmetric, additive rank error O(log(1/ε) + log(εN)) O(log(1/ε) + log(εN)) With care Deterministic. The classic streaming quantile algorithm. Space grows logarithmically with N. Not easily parallelisable.
Q-Digest O((1/ε) · log σ) where σ = universe size |rank(v̂) − rank(v)| ≤ εN (deterministic) Symmetric, additive rank error O(log σ) O(log σ) Yes Requires bounded integer universe [1, σ]. Tree-based compression. Straightforward merge. Used in distributed settings.
t-Digest O(δ) (δ = compression param, typically 100–300) No formal proof; empirically excellent at extreme quantiles Symmetric; tighter at tails empirically O(log δ) O(δ) Yes Heuristic: clusters centroids using a scale function that allocates more resolution to tails. Extremely popular in practice (Elasticsearch, Apache Spark). Lack of formal guarantees is a known limitation.
KLL Sketch O((1/ε) · log log(1/δ)) — near optimal |rank(v̂) − rank(v)| ≤ εN w.p. ≥ 1−δ Symmetric, additive rank error (probabilistic) O(1) amortised O(log(1/ε)) Yes Karnin-Lang-Liberty (2016). Near-optimal space. Randomised compaction. The best-known practical algorithm with provable guarantees. Implemented in Apache DataSketches.
DDSketch O((1/α) · log(max/min)) bins Returned quantile value within (1 ± α) of true value Relative error on value (not rank) O(1) O(log(1/α)) Yes Datadog (2019). Logarithmic binning. Guarantees on the value rather than the rank. Excellent for latency percentiles where relative accuracy at extreme quantiles matters (e.g., p99.9 of response times).
ReqSketch O((1/ε) · √(log(1/(εδ)))) |rank(v̂) − rank(v)| ≤ ε · rank(v) w.p. ≥ 1−δ Relative rank error O(1) amortised O(log(1/ε)) Yes Relative-Error Quantile sketch. Provides relative (not additive) rank error, so accuracy is proportional to rank. Better for extreme quantiles than additive-error sketches. From Apache DataSketches.
Moments Sketch O(k) (k = number of moments) Depends on distribution; exact for distributions characterised by k moments Symmetric O(k) O(k³) (moment inversion) Yes (add moments) Stores the first k moments. Inverts via maximum entropy optimisation. Very compact but accuracy depends on how well the distribution is captured by k moments. Poor on multimodal data.

5. Similarity Estimation Symmetric

Query: "sim(A, B) = ?" → ŝ ≈ sim(A, B)

These structures produce compact signatures (sketches) of sets or vectors such that similarity can be estimated from the signatures alone, without access to the original data. The estimators are generally unbiased with symmetric error.

Structure Similarity Metric Signature Size Error Error Direction Merge Notes
MinHash Jaccard similarity: J(A,B) = |A∩B| / |A∪B| k hash values per set (typically k = 128–256) Std. dev. ≈ √(J(1−J)/k) Symmetric (unbiased) Yes (union via min) Each signature element is min(h(x)) for x in S. P(min h(A) = min h(B)) = J(A,B). Estimate J by fraction of matching signatures. Foundation for LSH-based near-duplicate detection.
b-Bit MinHash Jaccard similarity (approximate) k × b bits per set (b typically 1–2) Slightly higher variance; introduces small bias Approximately symmetric (slight bias) Yes Stores only the lowest b bits of each MinHash value. Dramatically reduces space (e.g., 32× at b=1). Bias correction formula exists but is imperfect at extreme similarity values. From Li & König (2010).
SimHash Cosine similarity / angular distance d-bit fingerprint per vector Hamming distance / d ≈ θ/π (where θ = angle) Symmetric No Charikar (2002). Projects high-dimensional vectors to binary fingerprints via random hyperplane rounding. P(bit match) = 1 − θ(A,B)/π. Used in web deduplication (e.g., Google). Not suitable for Jaccard.
Locality-Sensitive Hashing (LSH) Various (Jaccard, cosine, Euclidean, Hamming) L × k hash values (L tables, k concatenated hashes) One-sided on retrieval: may miss similar items (false negatives), but reported items satisfy distance bounds w.h.p. One-sided on recall N/A (index structure) Framework, not a single structure. Hashes similar items to same bucket with high probability. Parameters trade recall (1 − FNR) against query time. Sub-linear approximate nearest neighbour search.

6. Set-Operation Sketches Symmetric

Query: "|A ∩ B| = ?, |A ∪ B| = ?, |A \ B| = ?" → approximate cardinalities

While HyperLogLog supports union (via register-wise max), it does not natively support intersection or difference with bounded error. These structures extend cardinality estimation to full set algebra.

Structure Operations Space Error Merge Notes
Theta Sketch Union, intersection, difference (A∩B, A∪B, A\B) with cardinality estimates O(k · log U) bits (k retained hashes) ~1/√k relative error; degrades for small intersections Yes Based on KMV (k minimum values) framework. Retains hash values below a threshold θ. Set operations are exact on the retained hashes; cardinality is estimated from the result. Error worsens when intersection is small relative to union. Implemented in Apache DataSketches.
Tuple Sketch Same as Theta, with associated summary values per key O(k · (log U + S)) where S = summary size Same as Theta for cardinality; exact on matched keys Yes Extension of Theta Sketch that associates arbitrary summary data (e.g., sum, mean) with each retained hash key. Enables approximate group-by / join operations. Apache DataSketches.
HLL + Inclusion-Exclusion Union (native), intersection (via |A∩B| = |A| + |B| − |A∪B|) O(m) per sketch Poor for intersection when |A∩B| ≪ |A∪B| (catastrophic cancellation) Yes (union only) Intersection via inclusion-exclusion amplifies relative error. Only usable when intersection is a substantial fraction of union. Theta Sketch is strongly preferred for intersection queries.

9. Glossary of Terms & Acronyms

Acronyms

AMQ
Approximate Membership Query — a class of data structures that answer "is x in set S?" with possible false positives but no false negatives.
CMS
Count-Min Sketch — a frequency estimation structure using d×w counter arrays with one-sided overestimate guarantees.
CPC
Compressed Probability Counting — Kevin Lang's cardinality estimation algorithm that compresses "surprising" register values for improved space efficiency.
DDSketch
Distributed Distribution Sketch — a quantile sketch using logarithmic binning to provide relative-error guarantees on quantile values. Developed at Datadog.
FM
Flajolet–Martin — refers to the foundational 1985 probabilistic counting algorithm (PCSA) by Philippe Flajolet and G. Nigel Martin.
FNR
False Negative Rate — the probability that a structure incorrectly reports an element as absent when it is actually present.
FP
False Positive — an incorrect report that an element is present in a set when it is not.
FPR
False Positive Rate — the probability of a false positive occurring, typically denoted ε. The information-theoretic lower bound for AMQ structures is n·log₂(1/ε) bits.
GF(2)
Galois Field of order 2 — the finite field with elements {0, 1} and operations XOR (addition) and AND (multiplication). Used in Ribbon filter construction.
GK
Greenwald–Khanna — a deterministic streaming quantile algorithm with O((1/ε)·log(εN)) space.
HLL
HyperLogLog — the standard practical cardinality estimation algorithm using harmonic mean of register values.
HLL++
HyperLogLog++ — Google's improved variant of HyperLogLog with sparse representation and empirical bias correction.
KLL
Karnin–Lang–Liberty — a near-optimal randomised quantile sketch with provable space bounds.
KMV
K Minimum Values — a cardinality and set-operation framework that retains the k smallest hash values from a set.
LSH
Locality-Sensitive Hashing — a framework for approximate nearest-neighbour search that hashes similar items to the same bucket with high probability.
PCSA
Probabilistic Counting with Stochastic Averaging — the original Flajolet–Martin cardinality estimation algorithm using multiple bitmaps.
SIMD
Single Instruction, Multiple Data — a CPU parallelism model where one instruction operates on multiple data elements simultaneously. Relevant to Morton filter's cache-line access patterns.
w.h.p.
With high probability — a statement that holds with probability ≥ 1 − 1/nc for some constant c > 0, where n is a problem parameter.
w.p.
With probability — shorthand for "with probability at least", typically followed by a bound like 1−δ.

Mathematical Notation

ε (epsilon)
The error/accuracy parameter. In AMQ structures, ε is the false positive rate. In frequency/quantile sketches, ε bounds the additive or relative error. Smaller ε → more space.
δ (delta)
The failure probability parameter. The structure's guarantee holds with probability ≥ 1−δ. Smaller δ → higher confidence → more space (typically logarithmic in 1/δ).
N
The total number of items in the stream (counting multiplicities), i.e. the stream length.
n
The number of distinct elements inserted into the structure.
m
The size of the structure's primary storage (e.g., number of bits in a Bloom filter, number of registers in HyperLogLog).
k
Overloaded: in Bloom filters, the number of hash functions. In KMV/MinHash, the number of retained values. In frequency algorithms, the number of monitored counters.
U
The size of the universe of possible element values (used in cardinality estimation space bounds).
σ (sigma)
The size of the integer universe in Q-Digest, i.e. the range of possible values [1, σ].
f(x)
The true frequency (count) of element x in the stream.
f̂(x)
The estimated frequency of element x as returned by the sketch.
ρ(·)
The function that counts the number of leading zeros in the binary representation of a hash value. Central to HyperLogLog and related algorithms.
‖ftail‖₂
The ℓ₂ (Euclidean) norm of the frequency vector excluding the top-k elements. Used in Count Sketch's error bound — tighter than CMS's ℓ₁ bound for skewed distributions.
O(·)
Big-O notation — asymptotic upper bound on growth rate, suppressing constant factors and lower-order terms.
φ (phi)
A quantile parameter in [0, 1]. The φ-quantile is the value at rank φ·N in the sorted stream.
α (alpha)
In Cuckoo filters, the load factor (fraction of occupied slots). In DDSketch, the relative accuracy parameter controlling bin width.
θ (theta)
In Theta Sketch, the sampling threshold — only hash values below θ are retained. In SimHash, the angle between two vectors.

Technical Terms

Additive rank error
A quantile error guarantee of the form |rank(v̂) − rank(v)| ≤ εN, where the absolute error bound scales with stream length N. Contrast with relative rank error.
Bias correction
An adjustment applied to a raw estimator to remove systematic over- or under-estimation. HyperLogLog applies corrections at small and large cardinality ranges; HLL++ uses empirical correction tables.
Cache line
The smallest unit of data transferred between CPU cache and main memory (typically 64 bytes on modern x86). Blocked Bloom and Morton filters are designed so each query accesses exactly one cache line.
Cardinality
The number of distinct elements in a set or multiset. Cardinality estimation structures approximate this count in sub-linear space.
Compaction
In KLL sketches, the process of reducing the number of stored items by randomly discarding every other item from a sorted buffer. This introduces bounded error while halving space.
Conservative update
An optimisation for Count-Min Sketch where, on insertion, only the minimum-valued counters among the k positions are incremented. Reduces overestimation in practice but breaks mergeability.
Cuckoo hashing
A hashing scheme where each element has two possible locations. If both are occupied, an existing element is "kicked out" to its alternate location. Basis of Cuckoo filter's insert mechanism.
Deterministic bound
An error guarantee that holds unconditionally on all inputs, with no probabilistic qualification. Contrast with probabilistic bound.
Epoch-based
A stream processing strategy that divides the stream into fixed-size windows (epochs) for periodic maintenance. Used by Lossy Counting to prune low-frequency items.
False negative
An incorrect report that an element is absent from a set when it is present. AMQ structures guarantee zero false negatives (with the exception of Stable Bloom Filter, which trades FNs for bounded memory).
False positive
An incorrect report that an element is present in a set when it is not. All AMQ structures accept a tuneable false positive rate ε to achieve sub-linear space.
Fingerprint
A short hash or signature of an element (typically a few bits), stored in place of the element itself. Used in Cuckoo, Xor, Fuse, and Ribbon filters. Fingerprint length directly controls the false positive rate.
Harmonic mean
The reciprocal of the arithmetic mean of reciprocals: H = n / Σ(1/xᵢ). HyperLogLog uses the harmonic mean of 2^(register values) to estimate cardinality, which is less sensitive to outlier registers than the geometric mean.
Hash collision
When two distinct elements produce the same hash value (or map to the same bucket/position). The fundamental cause of false positives in AMQ structures and overestimation in Count-Min Sketch.
Heavy hitter
An element whose frequency exceeds a specified fraction of the stream length (e.g., f(x) > εN). Finding all heavy hitters is a core streaming problem addressed by Space-Saving, Misra-Gries, and related algorithms.
Hypergraph peeling
An algorithmic technique for constructing static filters (Xor, Binary Fuse). Elements define hyperedges on a random hypergraph; "peeling" iteratively removes degree-1 vertices to find an assignment of fingerprints to positions.
Inclusion-exclusion
The set identity |A∩B| = |A| + |B| − |A∪B|. When applied to sketch-estimated cardinalities, the subtraction amplifies relative error (catastrophic cancellation), making it impractical when |A∩B| ≪ |A∪B|.
Information-theoretic lower bound
The minimum number of bits required to represent a solution to a given problem. For AMQ with n elements at FPR ε, the lower bound is n·log₂(1/ε) bits. Structures approach but cannot beat this limit.
Jaccard similarity
A set similarity metric: J(A,B) = |A∩B| / |A∪B|, ranging from 0 (disjoint) to 1 (identical). Estimated by MinHash.
Leading zeros
The count of consecutive 0-bits at the start of a hash value's binary representation. Observing k leading zeros occurs with probability 2⁻ᵏ, so the maximum observed is a proxy for log₂(cardinality). The core observable in HyperLogLog.
Linear probing
A hash table collision resolution strategy where, on collision, the next sequential slot is checked. Quotient filters use this to achieve cache-friendly sequential memory access.
Load factor
The fraction of occupied slots in a hash-based structure (n/m). Higher load factors mean better space utilisation but increase collision rates and operation costs.
Logarithmic binning
A bucketing strategy where bin boundaries are geometrically spaced (each bin is (1+α)× wider than the previous). Used by DDSketch to guarantee relative error on quantile values regardless of scale.
Maximum entropy
An optimisation principle: among all distributions consistent with observed moments, choose the one with maximum Shannon entropy. Used by Moments Sketch to reconstruct a distribution from its first k moments.
Median-of-means
An estimator that partitions data into groups, computes the mean of each group, then takes the median. Used by Count Sketch to achieve concentration bounds while remaining unbiased. More robust to outliers than a single mean.
Merge / mergeability
The ability to combine two independently constructed sketches into a single sketch representing the union of their inputs, without access to the original data. Critical for distributed and parallel computation.
Multiset
A collection that allows repeated elements (unlike a mathematical set). Frequency and quantile sketches operate over multisets.
One-sided error
An error guarantee where mistakes can only occur in one direction. E.g., Bloom filters may say "yes" incorrectly (false positive) but never "no" incorrectly (false negative). Also called asymmetric error.
Probabilistic bound
An error guarantee that holds with probability ≥ 1−δ. The structure may exceed the error bound with probability δ, but this can be made arbitrarily small at the cost of more space.
Quantile
The φ-quantile of a dataset is the value below which fraction φ of the data falls. The 0.5-quantile is the median; the 0.99-quantile (p99) is the 99th percentile.
Register
In HyperLogLog, one of m small counters (typically 5–6 bits) that stores the maximum number of leading zeros observed among elements hashing to that register's bucket.
Relative rank error
A quantile error guarantee of the form |rank(v̂) − rank(v)| ≤ ε·rank(v), where the error is proportional to the rank itself. Provides better accuracy at extreme quantiles than additive rank error. Used by ReqSketch.
Scale function
In t-Digest, a mapping that controls how much compression is applied at different quantile positions. The default scale function allocates more resolution (less compression) at the tails (near 0 and 1) than at the centre.
Sketch
A compact, lossy summary of a dataset that supports specific approximate queries. Used generically across all categories in this document. Formally, a linear sketch satisfies sketch(A∪B) = sketch(A) + sketch(B).
Stochastic averaging
A variance reduction technique that partitions the hash space into m substreams (using the first log₂(m) bits) and averages the results. Used in PCSA and all HyperLogLog-family algorithms.
Symmetric error
An error guarantee where the estimate may be above or below the true value with roughly equal probability. The error is typically bounded as |estimate − true| ≤ ε·true w.h.p.
